    participant M as Mota
    participant R as Router

    Note over M: Despierta y envía datos

    Note over R: Procesa datos
    Note over R: Revisa si hay config pendiente: SÍ

    Note over M: 1. Marca datos como enviados<br/>2. Aplica nueva configuración (sendInterval)

    M->>R: DATA_CONF_ACK (0x22)
    Note right of M: Payload: struct ControlData<br/>(Confirma cambio de config)

    Note over R: Marca config como "Sincronizada"

    Note over M: Vuelve a dormir con nuevo intervalo
